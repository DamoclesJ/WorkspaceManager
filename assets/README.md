# WorkspaceManager Icon Assets

- `assets/workspace-manager.png` is the approved source artwork and should be preserved for future exports.
- `assets/workspace-manager.ico` is the Windows runtime resource loaded by the Tray Controller.

The ICO contains 16×16, 24×24, 32×32, 48×48, 64×64, 128×128, and 256×256 representations with transparency retained from the source PNG.

If the ICO is absent or cannot be loaded, the Tray Controller falls back to the Windows application icon.
