# WorkspaceManager 需求文档

> 状态：草稿  
> 最后更新：2026-08-04  
> 说明：本文档基于 2026-08-04 确认的产品方向整理。硬件细节和实现可行性仍需验证。

## 1. 背景与问题

用户日常使用 Mac mini M4 和 Windows 台式机构成混合工作环境，显示器可能连接多台主机，键鼠通过 Logitech Flow 协同。当前切换设备时通常需要手动完成多步操作：

- 唤醒或睡眠目标主机。
- 切换每台显示器的输入源。
- 调整 Windows 的双屏/单屏模式。
- 确认 Logitech Flow 能正确跟随。

手动执行步骤容易遗漏或反复，影响切换效率。

## 2. 项目定位

WorkspaceManager 是一个面向个人的桌面环境自动化管理工具，通过一个桌面快捷控制入口，把上述设备状态调整编排成可重复、可回退、尽量无感的一次切换。

## 3. 目标用户

- 本人：同时使用 Mac mini M4 和 Windows 台式机的单用户场景。
- 不面向团队协作或通用企业环境。

## 4. 核心使用场景

### 4.1 场景一：从 Windows 切到 Mac

1. 用户在控制入口选择“切到 Mac”。
2. Mac mini M4 被远程唤醒。
3. 显示器输入源自动切换到 Mac 对应接口。
4. Windows 按当前场景调整为合适状态。
5. Logitech Flow 完成键鼠跟随，用户无感进入 Mac 工作状态。

### 4.2 场景二：从 Mac 切到 Windows

1. 用户在控制入口选择“切到 Windows”。
2. Windows 台式机被唤醒（如适用）。
3. 显示器输入源自动切换到 Windows 对应接口。
4. Windows 自动应用双屏或单屏显示模式。
5. Logitech Flow 完成键鼠跟随，用户无感进入 Windows 工作状态。

### 4.3 场景三：快捷状态控制

用户在控制入口可以查看两台设备、显示器和 Flow 的当前状态，并执行单项操作，例如只唤醒 Mac、只切换显示器输入、只切换 Windows 显示模式。

## 5. 功能需求

### 5.1 Mac mini M4 电源管理

- 远程唤醒 Mac mini M4。
- 远程让 Mac mini M4 进入睡眠。
- 查询 Mac mini M4 当前电源状态。
- 唤醒和睡眠操作需要可重复执行，不应重复触发造成异常。

### 5.2 显示器输入源管理

- 查询每台显示器的当前输入源（能力可行时）。
- 将显示器输入源切换到指定主机。
- 多显示器场景下应能按顺序或并行完成切换。
- 输入源控制能力依赖显示器型号，需要支持可配置映射。

### 5.3 Windows 显示模式管理

- 将 Windows 切换为双屏模式。
- 将 Windows 切换为单屏模式。
- 查询 Windows 当前显示模式。
- 切换后应保持 Windows 已登录会话的连续性。

### 5.4 Logitech Flow 协同

- 切换完成后确保键鼠可跟随目标主机。
- 在能力允许范围内自动触发或确认 Flow 切换。
- 无法自动控制 Flow 时，应给出明确提示而不是静默失败。

### 5.5 桌面快捷控制入口

- 提供常驻的快捷入口，例如菜单栏、系统托盘或桌面悬浮入口。
- 一键执行完整切换场景。
- 提供单项控制入口。
- 展示最近一次操作结果和当前设备状态。

### 5.6 切换编排

- 支持“切到 Mac”和“切到 Windows”两个完整场景。
- 每一步执行前检查前置条件，执行后校验结果。
- 任一步失败时应停止后续步骤并显示失败原因。
- 操作应具备幂等性，重复执行不应产生副作用。

## 6. 无感切换要求

- 常规切换尽量无需用户额外确认或手动补做步骤。
- 切换过程耗时应在可接受范围内，具体目标待实测后确认。
- 不应因自动化失败导致设备长期处于非预期状态。
- 所有操作都应提供手动回退方式。

## 7. 非功能需求

- 本地优先：控制与状态信息只在本机局域网内流转，不依赖云服务。
- 可靠性：自动化步骤需要状态校验和重试策略。
- 安全：局域网内设备间通信需要鉴权，避免误触发。
- 可维护性：平台相关能力集中封装，便于替换显示器、主机或 Flow 实现。
- 可观测性：记录操作日志和状态变更，便于排查问题。

## 8. 明确不做

- 移动端远程控制和公网访问。
- 通用 KVM 或企业级设备管理。
- 自动改造显示器、主机或其他硬件。
- 替代 Logitech Options+ 的键鼠配置管理。

## 9. 术语

- 主机（Host）：Mac mini M4 或 Windows 台式机。
- 显示器（Display）：参与输入源切换的物理显示器。
- 输入源（Input Source）：显示器当前使用的物理输入接口。
- Flow：Logitech Flow 提供的跨主机键鼠协同能力。
- 场景（Scene）：一组可复用的设备状态目标，例如“切到 Mac”或“切到 Windows”。
- 切换（Transition）：从当前场景切换到目标场景时执行的自动化步骤序列。

## 10. 待确认问题

- 两台主机分别连接哪些显示器接口和输入源？
- 显示器是否支持 DDC/CI 或官方控制协议？
- Windows 台式机是否支持远程唤醒，是否需要始终开启电源状态？
- Logitech Flow 是否提供可调用的自动化接口，还是只能通过界面或模拟操作触发？
- 控制入口优先运行在 Mac 还是 Windows？
- 切换完成时间的目标值是多少？
